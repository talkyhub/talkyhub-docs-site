# Каналы

Канал (inbox) — это источник обращений клиентов. Все сообщения из подключённых
каналов попадают в общий список диалогов рабочего пространства.

## Электронная почта

Почтовый канал работает по стандартным протоколам:

- **IMAP** — TalkyHub периодически забирает новые письма из указанной папки
  почтового ящика и превращает каждую цепочку в диалог;
- **SMTP** — ответы агентов уходят клиенту от адреса ящика.

При подключении укажите:

| Параметр | Описание |
| --- | --- |
| Адрес | Почтовый адрес, с которого клиенты пишут и на который уходят ответы |
| IMAP‑хост и порт | Сервер входящей почты (например, `imap.example.com:993`, SSL) |
| SMTP‑хост и порт | Сервер исходящей почты (например, `smtp.example.com:465`, SSL) |
| Логин и пароль | Учётные данные ящика (или пароль приложения) |

:::tip Один ящик — один канал
Не подключайте один и тот же почтовый ящик к нескольким каналам: два канала
будут одновременно вычитывать одну и ту же папку IMAP и дублировать диалоги.
TalkyHub предупредит о попытке создать второй канал на тот же ящик.
:::

### Проверка и изменение учётных данных

Настройки подключения канала можно посмотреть и изменить через интерфейс или
через API. Пароль в ответах API не возвращается — при необходимости его нужно
задать заново.

### Сохранение переносов строк

Текст входящих писем сохраняется как есть: переносы строк и абзацы клиента
остаются в теле диалога, тема письма становится темой обращения.

## ВКонтакте

Канал ВКонтакте принимает сообщения сообщества. Для подключения понадобится
токен сообщества с правами на работу с сообщениями и настроенный Callback API
или Long Poll — TalkyHub проведёт по шагам в интерфейсе.
