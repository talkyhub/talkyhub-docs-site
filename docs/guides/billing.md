# Тарифы и оплата

TalkyHub предлагает два способа оплаты тарифного плана.

## 1. Онлайн‑оплата (для всех)

Выберите план и оплатите картой, через СБП, T‑Pay или SberPay. Оплата
проходит через эквайринг, план подключается автоматически после подтверждения
платежа. По итогам оплаты формируется чек по 54‑ФЗ и, при желании, отправляется
на указанный email — адрес можно изменить перед оплатой.

## 2. Счёт для юридических лиц (B2B)

Если вы платите от организации, заполните платёжные реквизиты. Достаточно ввести
ИНН — остальные реквизиты подтянутся автоматически по данным из открытых
реестров. После этого станет доступен счёт с QR‑кодом для оплаты через
интернет‑банк (T‑Bank B2B).

:::note Реквизиты — сначала карточка организации
Способ оплаты по счёту появляется только после того, как заполнены платёжные
реквизиты. До этого доступна онлайн‑оплата.
:::

## Реквизиты по ИНН

Поиск организации по ИНН доступен как отдельная возможность: по ИНН
возвращаются наименование, адрес и другие реквизиты для автозаполнения формы.

## Фискализация

Чеки формируются через оператора фискальных данных (АТОЛ Онлайн). Предмет
расчёта — IT‑услуга, способ расчёта — полный расчёт.
