# Работа с диалогами

Диалог (conversation) — это переписка с одним клиентом в рамках одного канала.
Каждое входящее письмо или сообщение либо продолжает существующий диалог, либо
создаёт новый.

## Жизненный цикл

1. **Открыт** — новое обращение, ожидает ответа агента.
2. **В работе** — агент назначен и отвечает клиенту.
3. **Отложен** — ответ дан, диалог ждёт реакции клиента.
4. **Закрыт** — вопрос решён.

Статус меняется вручную агентом или автоматически при ответе.

## Инструменты агента

- **Назначение** — диалог можно назначить на себя, на другого агента или на
  команду.
- **Метки (labels)** — теги для категоризации обращений; общие для диалогов и
  контактов.
- **Внутренние заметки** — приватные комментарии внутри диалога, которые не
  видит клиент.
- **Быстрые ответы (canned responses)** — заготовленные шаблоны частых ответов.
- **CSAT** — после закрытия диалога клиенту можно отправить опрос
  удовлетворённости.

## Ответы по email

Ответ агента уходит клиенту письмом от адреса канала. В подпись подставляется
отображаемое имя агента (настраивается). Тема письма и цепочка сохраняются, так
что клиент видит привычный тред.
