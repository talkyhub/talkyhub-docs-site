# Вебхуки

TalkyHub принимает входящие вебхуки от подключённых платформ и платёжных
сервисов. Такие эндпоинты вызываются самими платформами, а не вашим кодом.

## Каналы

- **ВКонтакте** — Callback API сообщества доставляет новые сообщения на
  соответствующий эндпоинт вебхука; TalkyHub подтверждает приём и создаёт
  диалог.

## Платежи

- **Эквайринг** — уведомления о статусе платежа приходят на служебный эндпоинт и
  проверяются по подписи (токену); при успешном платеже план активируется.
- **Фискализация** — статус чека приходит от оператора фискальных данных и
  сопоставляется с платежом.

:::warning Проверка подлинности
Служебные эндпоинты вебхуков доступны без авторизации, но каждое уведомление
проверяется: у платёжных — по токену/подписи, у каналов — по идентификаторам
платформы. Невалидные запросы отклоняются.
:::
