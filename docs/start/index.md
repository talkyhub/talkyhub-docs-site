# Быстрый старт

TalkyHub — это платформа для общения с клиентами: все обращения из почты,
мессенджеров и социальных сетей собираются в один общий инбокс, а команда
поддержки отвечает на них из единого рабочего пространства.

Чтобы начать работу, понадобится несколько шагов.

## 1. Создайте рабочее пространство

Зарегистрируйтесь на [talkyhub.ru](https://talkyhub.ru) и создайте рабочее
пространство (workspace). Рабочее пространство — это ваша команда: у него есть
свои каналы, диалоги, контакты и участники.

## 2. Подключите первый канал

Канал (inbox) — это источник обращений. TalkyHub поддерживает:

- **Электронную почту** — по протоколам IMAP (приём) и SMTP (отправка);
- **ВКонтакте** — сообщения сообщества;
- и другие каналы, которые добавляются в разделе **Каналы**.

Как подключить почтовый ящик и настроить учётные данные — в разделе
[Каналы](../channels/index.md).

## 3. Пригласите агентов

Пригласите коллег по email. Каждый участник получает роль (администратор или
агент) и доступ к диалогам рабочего пространства.

## 4. Отвечайте на обращения

Новые письма и сообщения автоматически превращаются в диалоги. Агент берёт
диалог в работу, отвечает клиенту, ставит метки и закрывает обращение. Подробнее
— в разделе [Работа с диалогами](../guides/conversations.md).
